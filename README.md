SillyTavern 低内存角色库

搜索、收藏、排序和抽取角色。闲置角色保留头像和轻量占位，打开时按需加载正文。聊天和群聊仍由酒馆管理。

## 第一次安装基础模式

1. 在酒馆打开「扩展程序 → 安装扩展程序」，输入仓库地址：
   ```text
   https://github.com/wice2261-ux/SillyTavern-Character-Library
   ```
2. 刷新页面，展开顶部扩展区的「角色库」，确认显示版本和「运行模式：基础」。
3. 点击「启用自动收回」，核对整理数量和预计空间后确认。日常管理从底部魔法棒菜单的「角色库」打开，也可以用右侧书本按钮。

基础模式只需前端。手动安装时，在 Release 的 **Assets** 里下载 `character-library-2.3.2-frontend.zip`，按安装说明解压。若酒馆已能正常打开角色列表，可以先用基础模式。

## 使用增强模式

如果首次读取大量完整角色卡就出现内存不足，可由服务器操作者评估增强模式，停服接管后再启动酒馆。请按安装说明安装前端及可选后端，再用交接工具接管账户。**设置显示「运行模式：增强」才表示已经接管**。「已检测到增强后端」仅表示服务可用。

## 日常使用

- 角色库支持搜索、四类排序、收藏和批量管理。导入默认同名另存，也可选跳过或替换。抽卡默认 3 张，可选 1–12 张，按当前搜索范围抽取。
- 默认管理目标为 8 张在线卡、192 MiB 活动正文估算。当前聊天、群成员及准备或保存中的角色会受到保护。收藏默认只高亮和置顶。开启「保持收藏卡加载」后，只保护已经加载的收藏卡。
- 专用世界书可手动生成，自动更新默认关闭。生成后在「世界书 → 选择以编辑」搜索「角色库资料」。显示「本次已核对」但搜不到时，刷新酒馆页面再查看。生成条目默认禁用，且不会自动绑定。

## 备份与卸载

「导出恢复资料」只保存目录和归档引用。完整备份请复制整个酒馆账户目录。卸载前，基础模式点「恢复全部并停用自动收回」，增强模式点「恢复完整 PNG」。确认恢复成功并能打开角色和历史后，再卸载。增强模式也可先交还基础模式，继续由前端管理。

验证基线为 SillyTavern 1.18.0、Node.js 24.15.0、酒馆助手 4.12.0。TauriTavern 和其他分支尚未实测。原创代码采用 [MIT](LICENSE)，第三方许可见[声明](THIRD_PARTY_NOTICES.md)。
