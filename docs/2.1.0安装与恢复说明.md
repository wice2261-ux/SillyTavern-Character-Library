# 2.1.0 安装与恢复说明

日期：2026-11-17。本次为本地交付，不代为更新GitHub或部署生产。

## 安装和升级

公开仓库更新为2.1后，在酒馆扩展程序的Install Extension输入项目GitHub地址即可；若远端尚未更新，安装的仍是远端版本。本地安装包按根manifest及extension目录结构放置，刷新页面加载。

不需要服务端插件、源码适配、SQLite或自定义Docker镜像。Node要求沿用宿主。首次受测组合沿用ST1.18.0／Node24.15.0／助手4.12.0；实际本轮与沿用测试范围见验证记录。

2.0升级前保留原包及完整账户备份。2.1未改变目录schemaVersion、正文格式或占位标记，无须仅为此次升级恢复全库；替换扩展后刷新，原管理状态沿用。从1.x退出旧服务端和适配的步骤仍按原说明执行，不能让两套收回器同时接管。

## 可选资料世界书

「自动更新专用世界书」默认关闭，「手动更新世界书」独立可用。手动更新不会开启自动模式；关闭自动模式保留已创建资料。

自动更新只跟随已提交管理操作，批量操作合并；切卡、心跳和收回不触发。最近游玩和导入时间在实际更新时顺带刷新，不是实时仪表盘。

书中条目只有轻量资料，默认禁用且不绑定。用户自己启用或绑定可能使其参与提示词。插件更新会覆盖生成条目的手工修改。若原生编辑器已打开旧副本，更新后重新打开查看最新内容。

同名用户书不会被接管；归属不符或网络错误显示失败，不影响角色操作。资料书删除后可手动重建；改名导致定位失效时不会扫描接管其他书。首次创建／空书歧义检查需要原生列表，其服务端可能解析其他世界书，自动开关默认关闭可避免日常额外开销。

## 备份、卸载与回退

完整账户备份包含角色、聊天、群聊及files目录中的character-library-v2.json和引用的cl2-*文件。专用世界书只是资料副本，不含全文。

2.1恢复资料保留format、directory和files字段，追加fileDetails引用信息。original是原PNG，current是当前归档，previous是必要前一版，operation.pending是未完成操作的文件引用，不一定是最新正文。文件可能同时承担多个角色。资料导出不访问正文，须与账户文件备份配套。

目录丢失时，在停服及完整备份后从恢复资料提取directory对象还原目录，同时交还files所列文件；不要将整个导出对象当目录。不能用原PNG覆盖后续编辑。恢复依据实际持有的目录、清单和文件，不保证自动发现所有遗失资料。

卸载前执行「恢复全部并停用自动收回」，确认无占位和失败项。关闭世界书自动更新不等于关闭角色收回。资料世界书可保留或由用户在原生界面删除；插件不会自动删除它。

回退2.0仍沿用相同正文格式，但应先关闭世界书自动更新再更换扩展；2.0不再维护资料副本，已有副本可手动删除。回退旧架构1.x前则必须先恢复全部。
