# 2.1.1 安装与恢复说明

日期：2026-11-17。本地源码与安装包不代表公开仓库已更新；本轮不代为发布或部署生产。

## 安装与升级

公开仓库更新到2.1.1后，在酒馆Install Extension输入项目GitHub地址即可安装；远端未更新时仍会安装旧版。保持根manifest与extension目录结构。无需服务端、原生适配、SQLite或新Node版本。

从2.1升级保留旧包与完整账户备份，替换扩展并刷新即可；目录、正文格式及占位标记未变，无须为升级恢复全库。从1.x退出旧服务端／适配和恢复冷卡的要求仍按原说明执行。

## 收藏默认只负责展示

「保持收藏卡加载」默认关闭，升级账户没有此字段也按关闭处理。收藏保持星标、高亮和可置顶，但与普通卡使用同一最近游玩顺序和收回条件，计入默认8张在线目标。

开启后，只保护已加载收藏卡，不在开启时或启动时批量恢复归库收藏卡。归库收藏卡使用前恢复，恢复后不自动收回；收藏不计入8张普通在线目标，但仍计入192 MiB活动估算。受保护数据可以使估算超目标，不能将预算当作硬内存上限。

关闭安排一次正常检查；当前聊天、群成员、准备中、保存中及恢复中的保护保持不变。未托管账户只保存开关，不因开启而自动迁移。

此前完整收藏卡可能先被原生启动列表解析，本版本不能追溯消除该次开销。在可操作状态关闭保护、完成闲置收回再重启，后续启动才会减少完整卡加载。首次启动已失败时不能保证只替换扩展就能解决，不提供启动前改写真实卡的工具。

## 收回取消与世界书

归档完成、写占位前发现新占用时，收回正常取消，角色保持完整在线，清除本次收回意图后可以继续保存。网络异常或原生写入结果不明仍保留恢复阶段，不能手动一概删除operation。

自动世界书开启时每次页面就绪核对一次轻量资料；失败独立显示，等待相关管理操作、手动更新或下一次启动，不周期重试。关闭自动更新时启动零世界书请求，已有书显示存在和上次成功时间，不保证是最新资料。

仅实际导出角色的标签名称和关联变化触发资料更新。世界书不含全文、不自动绑定，生成条目默认禁用；它是资料副本，不是备份。更新会覆盖生成条目的手动修改。手动按钮仍独立可用。

## 备份与卸载

完整备份包含账户角色、聊天、群聊及files目录的character-library-v2.json和引用的cl2-*文件。恢复导出提供目录和文件引用清单，不含正文。原始PNG不能覆盖之后的在线编辑。

卸载前执行「恢复全部并停用自动收回」并确认无占位及失败项。仅关闭收藏保护或世界书自动更新不等于停用角色管理。世界书可以保留或在原生界面删除。

回退2.1仍使用相同正文格式，但2.1会恢复“收藏始终保护”的旧行为，不识别新开关。回退前理解此内存变化；回退1.x前必须先恢复全部并退出当前架构。
